///
Как это работает

Три шага до готовой блок-схемы

Никаких специальных знаний. Просто опишите процесс — ИИ сделает всё остальное.

01
Скачайте инструкцию и передайте ИИ
Скачайте файл GOSTFlow_AI_Instruction.md и добавьте его в чат с любым ИИ — ChatGPT, Claude, Gemini или другим. Это системная инструкция, которая научит модель генерировать правильный JSON.
↓ Скачать ниже на странице
02
Опишите алгоритм своими словами
Напишите что угодно: бизнес-процесс, алгоритм программы, жизненный цикл запроса, инструкцию для сотрудника. ИИ разберётся в структуре и создаст JSON с блоками и связями по стандарту ГОСТ 19.701-90.
Поддерживаются русский и английский
03
Импортируйте в ГОСТФлоу одной кнопкой
Скопируйте JSON из ответа ИИ, откройте gostflow.sherhn.space и нажмите кнопку «↑ Импорт» в верхней панели. Блок-схема появится мгновенно. Затем её можно отредактировать, экспортировать в SVG или распечатать.
↑ Импорт → вставить JSON → готово
Пример разговора с ИИ
Вот инструкция (GOSTFlow_AI_Instruction.md). Нарисуй блок-схему: пользователь вводит логин и пароль. Если данные верны — вход. Если нет — показать ошибку и предложить повторить.
Понял. Вот JSON для ГОСТФлоу:
{ "nodes": [ { "id": "n1", "type": "start", "label": "Начало", ... },
  { "id": "n2", "type": "io", "label": "Ввод логина\nи пароля", ... },
  { "id": "n3", "type": "decision", "label": "Данные\nверны?", ... },
  ... ], "edges": [ ... ] }
↳ Вставьте этот JSON через кнопку «↑ Импорт» в ГОСТФлоу. Любые свойства текста можно изменить во вкладке Свойства.
///
Возможности

Что умеет инструкция

◆
Все фигуры ГОСТ
Начало/Конец, Процесс, Условие, Ввод/Вывод, Цикл, Подпрограмма, Параллельные действия и другие — по ГОСТ 19.701-90.
↻
Циклы и ветвления
ИИ корректно строит обратные стрелки, обходит блоки через waypoints, не допускает наложения линий.
⊞
Многолистовые схемы
Большие алгоритмы автоматически разбиваются на листы — основной процесс, подпрограммы, параллельные потоки.
Да/Нет
Метки по ГОСТ
Каждая ветка решения подписывается отдельным текстовым блоком «Да»/«Нет» — строго по стандарту.
🌍
Русский и английский
Пишите задачу на любом языке. Текст блоков и меток в схеме будет на вашем языке.
✓
Встроенная проверка
Инструкция содержит чеклист для ИИ: уникальные ID, один порт — одно соединение, валидный JSON без ошибок.
